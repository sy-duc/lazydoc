# Yêu cầu Training MCP

Cần setup MCP server cho team dev. Anh Minh nói là phải config trong Claude Code, dùng cái gì đó liên quan đến tool calling.

## Việc cần làm
- Tìm hiểu MCP là gì, tại sao cần dùng
- Cài đặt MCP server (chưa rõ dùng loại nào)
- Config file settings JSON ở đâu đó trong project
- Test thử với 1-2 tool đơn giản
- Training cho team vào thứ 5 tuần sau

## Ghi chú
- Budget: chưa rõ
- Anh Minh có gửi 1 link docs nhưng chưa tìm lại được
- Nghe nói có thể dùng stdio hoặc SSE gì đó
- Cần check xem Claude Code hỗ trợ version MCP nào
